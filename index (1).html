Hyper-V Enabler for Windows Home

Free download · turns on a feature Windows Home normally hides

Windows Home editions don't show Hyper-V in "Turn Windows features on or off," even though the files for it are already sitting on your system. This script registers those files and switches the feature on. Nothing else gets installed.

How to run it

  1. Download the file and save it somewhere you can find it, like your Desktop.
  2. Right-click it and choose Run as administrator. Double-clicking it normally won't work.
  3. If Windows shows a blue "Windows protected your PC" warning, click More info, then Run anyway.
  4. A command window opens and does its work — let it run, it can take a couple of minutes.
  5. When it says Press any key to continue . . ., press any key to close it.
  6. Restart your PC.
  7. After restarting, search for Hyper-V Manager in the Start Menu — it should now be there.
Save any open work before running it — it's changing a system component, so treat it like any other system-level tool.

What it actually does

It looks for the Hyper-V package files under Windows\servicing\Packages, registers each one with DISM, then enables the Hyper-V feature itself. Nothing is downloaded — it only uses what's already on your machine.

pushd "%~dp0"

dir /b %SystemRoot%\servicing\Packages\*Hyper-V*.mum >hyper-v.txt

for /f %%i in ('findstr /i . hyper-v.txt 2^>nul') do dism /online /norestart /add-package:"%SystemRoot%\servicing\Packages\%%i"

del hyper-v.txt

Dism /online /enable-feature /featurename:Microsoft-Hyper-V -All /LimitAccess /ALL

pause

Questions

Does it work on Windows 11 Home?
Yes, in most cases. If Hyper-V Manager doesn't show up after restarting, run the script a second time.
Is it safe?
It only turns on a component that's already part of your Windows installation. It doesn't reach out to the internet or touch anything unrelated.
I ran it and nothing changed.
Double-check you used "Run as administrator," then restart. That's the step people usually skip.
